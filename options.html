解析通道

内置直连解析器 X / 抖音 / B站 / 微博 / 通用网页嗅探 · 不经过第三方服务器
X 使用开源 fxTwitter / vxTwitter 只读 API；抖音使用官方分享页数据并把 playwm 换成 play 取无水印流；B站/微博使用各自公开接口。这些接口可能随平台改版失效，所以下面几条兜底通道很重要。
RC 全平台解析 与本机「抖音解析 无水印」快捷指令同源 · 开箱即用
从本机快捷指令中实测提取：先读取配置端点拿到 parse 地址，再 POST {"url":…,"sv":"1","client":"ios-shortcut-247","quality":"all"}。实测 B 站链接返回 code:0，含画质标签与 CDN 防盗链请求头（Referer）。配置端点可动态换域名，插件会自动跟随。
⚠️ 启用后，内置解析失败的链接会被发送给第三方服务 parse.rcuts.com（与快捷指令行为一致）。不想让链接离开本机就关掉此开关，改用「自定义解析 API」或本地 yt-dlp。
自定义解析 API 把 iOS 快捷指令里用的那个接口直接搬过来
插件会自动递归扫描返回的 JSON，找出所有 mp4 / m3u8 / CDN 视频地址；纯文本直链也支持。适合各种"短视频去水印"公共接口和你自己部署的服务。
Cobalt 实例 开源通用解析后端，覆盖 YouTube / TikTok / Instagram / Reddit 等
⚠️ 官方公共实例 api.cobalt.tools 已启用 JWT 授权，第三方调用会被拒绝（实测返回 error.api.auth.jwt.missing）。请自建实例（Docker 一条命令）或使用社区允许的实例，再填入地址。
本机桥接 / yt-dlp 注册一次即可启用「本机原生下载」；yt-dlp 仅用于合并高分音视频
只需一步：在终端进入本插件的 bridge 目录，执行下面命令注册桥接（扩展 ID 已自动带入）。本机原生下载不要求安装 yt-dlp，系统自带 Python 3 即可。

下载行为

本机原生下载（推荐，解决视频 CDN 防盗链）
授权本地通信并注册桥接后，直链会连同解析服务给的完整请求头（含 User-Agent / Referer）交给本机 Python 下载 —— 这正是快捷指令能下载成功的原因。浏览器扩展无法设置 User-Agent（Chrome 安全限制），所以视频直链常被 CDN 拒成 403 网页。音频一般不受影响，因此会出现「音频能下、视频不能下」。开启后不需要安装 yt-dlp。
右键 / Alt+D 解析成功后自动下载推荐画质
打开面板时自动读取剪贴板里的链接并解析
手动在面板里点「解析」时永远只展示画质列表，不会自动下载。

说明

· 插件需要「读取和更改所有网站数据」权限，才能在后台请求任意解析接口与视频 CDN（网页做不到，扩展可以）。所有解析都发生在你自己的浏览器里，插件不上传任何数据到我们的服务器——本项目没有服务器。
· 但「RC 全平台解析」「自定义解析 API」这类第三方通道会把你提交的链接发送给对应服务；默认只开启 RC 通道（与本机快捷指令同源），可在上方一键关闭。内置直连与本地 yt-dlp 不经过第三方解析服务。
· 公共解析接口随时可能限流、加鉴权或关停；长期稳定使用建议自建 Cobalt 或装 yt-dlp。
· 请仅下载你有权利保存的内容，遵守各平台服务条款与著作权规定，勿用于搬运、二次分发或商业用途。
